# 🥷 Calculadora Ninja

Uma calculadora web responsiva com uma temática sombria inspirada em elementos Ninja (Preto e Vermelho Carmesim). Desenvolvida estritamente com HTML5, CSS3 e JavaScript Vanila.

## 🚀 Funcionalidades
- Operações matemáticas básicas (Soma, Subtração, Multiplicação e Divisão).
- Tratamento de erros (como divisão por zero).
- Design responsivo adaptado para Desktop e Mobile.
- Correção automática de precisão para números de ponto flutuante.

## 📂 Como executar o projeto
1. Baixe os arquivos para uma pasta local.
2. Certifique-se de manter todos os arquivos (`index.html`, `style.css`, `script.js`) no mesmo diretório.
3. Dê um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador.
